<objective>
Put Spanish on the phone. A caller who speaks only Spanish completes a full claim end to end,
hearing Spanish for every sentence, with the same deterministic tariff figures an English caller
gets — and the multilingual demo beat is settled and rehearsable in whichever form the platform
actually supports.

Purpose: this is success criterion 5 on the channel that matters most to the pitch, and it is the
criterion most likely to be faked by flipping a config flag. 05-RESEARCH.md is unambiguous that
`enableMultilingualSupport` handles *input* and translates nothing this project has made
deterministic. Every hardened English string on the voice app is a literal in tool source; the
platform will happily let a Spanish-speaking caller hear a Spanish greeting followed by an English
decision sentence. That is the failure this plan exists to prevent.

Output: the voice app speaking Spanish end to end, a new voice version serving on `d28bbcb0`, and
a runbook a presenter can read standing up — or the previous voice version still serving and a
named failure. Success criterion 6 is enforced in the same breath: the English path is re-proven
on the same build, not assumed.
</objective>

   the first line of this plan until every assertion in Task 3 passes. The repoint is conditional

2. **Never `importApp`.** Direct `apps.patch` / `apps.tools.patch` / `apps.agents.patch` with an

   or reuse any zip, in any scratchpad, for any reason.
3. **Never read, echo, print or copy the source of `resolve_claim` or `send_claim_email`.** They
   hold a live Resend API key. The only permitted interaction is the scripted, filtered literal
   extraction and scripted replacement specified in Task 1, which prints counts, lengths and
   booleans and aborts before printing anything if its key checks fail. Filter tool listings by
   `displayName` in-script; never print a tool list whole.
4. **Write only to `6e01e4a5`.** Gate every mutating URL on that literal in-script; refuse
   `a2f621e4` and `9ae7a0c3` for any non-GET method.
5. **Determinism is not negotiable.** The claim amount, the excess, the on-the-spot limit and the
   claim reference come from the tariff, in both languages. Spanish is a **second deterministic
   string**, never a model translation. If a Spanish figure can only be produced by the model,
   the task has failed — do not ship it.
6. **Large instructions are edited by scripted `str.replace()` against the API only.** Replacement
   text lives in a file; the script asserts anchor uniqueness, replaces exactly one contiguous
   region, asserts a bounded length delta, PATCHes and reads back byte-for-byte, printing only
   lengths, booleans and excerpts under 200 chars. **Never compose an instruction inline in
   tool-call arguments** — three executor sessions have died doing exactly that.
7. **GTP surface is fragile and must be proven untouched.** Barge-in / interruption settings, DTMF
   config and timeout values inside `audioProcessingConfig` are byte-compared before and after the
   `synthesizeSpeechConfigs` edit. A Spanish voice entry must not silently reset them.
8. **Quota budget: two conversations, nine turns total**, run against the **DRAFT** app
   (`runSession` with no `config.deployment`), paced ≥55 s. At most one spaced retry of a single
   quota-failed turn. **No retry loops.** A conversation costs 120k–150k input tokens against a
   1,000/min limit.
9. **An agent cannot place a phone call.** Everything that requires the real GTP number is Task 4,
   a blocking human checkpoint.
</hard_constraints>
