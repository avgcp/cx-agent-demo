   `runSession` needed to drive a conversation. Gate this in-script: any request whose method is

   carry a live Resend API key. When listing tools, project to `displayName` (and, where needed,
   `executionType` / parameter *names*) inside the script — never print or write a whole tool
   resource. Tool *outputs* taken from a conversation record's `toolResponse` are claim data, not
   source, and are the sanctioned way to capture figures and strings.

   asserted by re-read, not assumed.

   1,000/min `RunSession LLM tokens` limit. This plan is budgeted at **at most two conversations,
   at most eight user turns total**, paced **≥55 s** apart. **No retry loops** — at most one spaced

   line is Task 3's human checkpoint and nothing else. Do not attempt to synthesise, dial or
   simulate a GTP call.

   baseline. Do not "fix" anything discovered here — open it as a blocker in the summary.
