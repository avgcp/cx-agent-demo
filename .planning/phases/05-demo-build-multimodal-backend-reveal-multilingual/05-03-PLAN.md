These apply to every task in this plan and are not negotiable.

1. **Never `importApp`.** It silently deletes server-only tools and reverts direct patches. Use
   `apps.patch` / `apps.tools.patch` / `apps.agents.patch` with an `updateMask`, read-verify-patch-verify.
2. **Every exported package on disk is STALE.** Do not read or reuse any zip in any scratchpad.
3. **Never read, echo or copy `resolve_claim`'s or `send_claim_email`'s source.** They hold a live
   Resend API key. Filter tool listings by `displayName` in-script; never print a tool list whole.
   Pin tool outputs from conversation records (`toolResponse`), which are claim data, not source.
4. **Never mutate the voice app or the fork in this plan.** Every mutating URL must be gated
   in-script on the literal `a2f621e4`; `6e01e4a5` and `9ae7a0c3` must be explicitly refused for
   writes. Reads of `6e01e4a5` are required and permitted.
5. **Never repoint any deployment in this plan.** Both `d28bbcb0` and `d7bfbb93` must serve the
   same `appVersion` at the end of this plan as at the start, asserted by re-read.
6. **Live conversations run against the DRAFT app** — a `runSession` with no `config.deployment`
   is accepted (proven in `260810-k5x`). The demo rig is never exposed to an unverified build.
7. **CES quota is the binding constraint.** A conversation costs 120k–150k input tokens against a
   1,000/min `RunSession LLM tokens` limit. This plan is budgeted at **two conversations, six
   turns total**. Pace turns ≥55 s apart. **No retry loops** — at most one spaced retry of a
   single quota-failed turn.
8. **Large instructions are edited only by scripted `str.replace()` against the API**, with the
   text kept in files and only lengths, booleans and short excerpts printed. No task in this plan
   edits an instruction, but the same discipline applies to any diagnostic read.
</hard_constraints>
